# Dynasty T20 — V2 changes
- Auction: one 3D BID button per human team (no dropdown), live LEADING state, Squad Scout panel for every team, SOLD pop-up with stamp animation, per-player sold prices recorded, bot bidding-war discipline (managers sometimes walk away near their cap).
- Players: Pakistan / Zimbabwe / Nepal removed (33 players). Added Root, Stokes, Crawley, Mills, Carey, J. Richardson, K. Richardson, Owen, Bavuma, Rossouw, L. Williams, Mathews.
- Match engine: set-batter model (20+ balls = hard to dislodge), new-batter vulnerability, pressure no longer pumps wicket odds, steep chases create hit-or-miss shots, dew (about 40% of matches, chasing side), per-innings batting/bowling day, pitch phases (seam early, spin middle).
- DRS: Pause can no longer erase a pending wicket; DRS is a blocking pop-up; Pause is disabled during any decision.
- UI: 3D buttons everywhere, panel animations, modal pop-ups.
- Calibration (scripts/calibrate.ts, 4000 matches): avg 171, ~5.4 wkts/inns (1st), chase win ~56%, all-out ~13%, 200+ ~16%.
